什么是 Agent？

一节课搞懂"智能体"的核心概念，
以及它和普通程序到底有什么不一样

一句话定义
Agent（智能体）是一种能自主感知环境、做出决策、执行动作以达成目标的软件实体。

💡个人解释

普通程序是"被驱动的执行者"——你说一步它做一步；Agent 是"主动的行动者"——给它一个目标，它自己想办法完成。

两种类比帮助感受差别：

🍳 普通程序像一张菜谱

厨师必须严格按"第 1 步、第 2 步、第 3 步"执行，没有自主判断空间。

👨‍🍳 Agent 像一个有经验的厨师

先看冰箱有什么（感知）、根据客人想吃什么（决策）、再动手做（执行）。

关键差异：普通程序只回答"怎么算"，Agent 要回答"该不该做、做什么、做不到怎么办"。

⚙️核心机制（一个闭环循环）

Agent 的运行本质是一个 感知 → 推理 → 行动 的闭环，每跑完一轮就根据新状态再决策，常常会循环多次直到目标完成：

1
感知 Perception
读输入（用户消息、屏幕、传感器数据、工具返回值），把外部状态翻译成 Agent 可理解的内部表征。
2
推理 Reasoning
基于当前状态 + 目标，调用大模型推理"下一步该怎么办"。常见做法：拆分任务、选择工具、判断是否要再观察。
3
行动 Action
调用具体工具或回复用户。执行后，环境会产生新状态，整个循环回到第 1 步继续。

现代 LLM Agent 通常还引入 记忆 Memory（短期对话上下文 + 长期知识库）和 工具 Tools（搜索 / 代码 / 数据库 / API）。这两块补齐了"感知"和"行动"的能力上限。

Agent ＝ 大模型做大脑 ＋ 感知-推理-行动闭环 ＋ 记忆 ＋ 工具

🌍具体应用场景

  • 智能客服：自动理解用户问题 → 检索知识库 → 必要时升级人工
  • 个人助手（Siri / 小爱同学）：听你说话 → 思考意图 → 调用手机功能执行
  • 自动驾驶：摄像头 / 雷达感知路况 → 决策加速 / 刹车 / 转向 → 控制车辆
  • 游戏 NPC：观察战况 → 选择策略 → 操控角色
  • 自动化办公：读邮件 → 判断紧急程度 → 自动回复或转交真人
  • 研究助理（Devin / AutoGPT 类）：读需求 → 拆解 → 写代码 / 跑测试 → 提交

⚠️易混淆点 / 边界

❓ Agent vs 普通程序到底差在哪？
普通程序是被驱动的执行者（按预设逻辑跑）；Agent 是被授权的行动者（自己决定下一步）。最直观的区别：把网线拔了，普通程序继续跑、Agent 常常就停了，因为它在主动观察外部。
❓ Agent = 智能 = ChatGPT？
ChatGPT 单轮问答是"被动响应"，严格说不是 Agent；给 ChatGPT 加上循环、工具、记忆，让它能自己决定何时停止，就变成 Agent。换句话说，大模型是 Agent 的"大脑"，Agent = 大脑 + 循环 + 工具 + 记忆。
❓ Agent 与 Skill / Prompt 的区别？
Prompt 是告诉 AI "这一次怎么说"的指令；Skill 是把好的 Prompt + 工具配置打包成可复用积木；Agent 是会自主决定用什么 Skill / 工具的主体。三者关系：Agent 指挥、Skill 干活、Prompt 是 Skill 的配方。
❓ 所有 AI 软件都算 Agent 吗？
不是。一个判断标准：能否在没人类指令的情况下自主推进任务直到完成。只做单次响应、必须人一步步指点的，不算 Agent；能拆任务、调用工具、跨多步达成目标的，才是 Agent。
